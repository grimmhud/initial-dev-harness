# Decisions

This directory separates durable decisions by ownership:

- `product/`: product decisions and business rules maintained by the root agent under user decision authority;
- `project/`: cross-cutting technical decisions maintained by `architect`.

PRDs and specs remain in `docs/planning/`; consolidated product state remains in `docs/product/product-definition.md`; the consolidated technical foundation remains in `docs/project/technical-foundation.md`.
