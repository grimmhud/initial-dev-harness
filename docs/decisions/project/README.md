# Project Decisions

Owner: `architect`.

Create `YYYY-MM-DD-<slug>.md` for durable cross-cutting technical decisions. Record status, context, decision, alternatives, tradeoffs, affected boundaries/dependencies, contract/data/operational impact, consequences, risks, migration or rollout strategy when applicable, date, and evidence.

Delivery-local design normally stays in the PRD/spec or linked Technical Design. Also record a canonical decision here when a technical change replaces an existing planned contract, even if feature-local; predecessor and successor link to it without duplicating rationale.
